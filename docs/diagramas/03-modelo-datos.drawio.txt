 MODELO DE DATOS — esquemas pay y aud
═══════════════════════════════════════════════════════════════════════════════

 COMO USARLO
   draw.io → Extras → Edit Diagram... → pegar el XML → OK → exportar PNG.

 QUE MUESTRA
   Las cuatro tablas y sus restricciones. Las restricciones estan dibujadas a
   proposito: son las que sostienen las garantias del reto, no comentarios.

     UQ_PAY_MOVIMIENTO_IDEMPOTENCIA  no cobrar dos veces la misma operacion
     UQ_PAY_MOVIMIENTO_QR            un QR se paga una sola vez
     CK_PAY_CUENTA_SALDO >= 0        nunca saldo negativo
     UQ_PAY_CUENTA_TITULAR           una cuenta por titular y moneda

   pay.CUENTA no tiene FK hacia CLIENTE ni COMERCIO: son tablas de otros
   microservicios y esa integridad se valida por gRPC antes de crear la cuenta.
